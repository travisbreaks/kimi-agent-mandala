# Kimi Agent Mandala — Agent Context

**Updated**: 2026-02-07 | **Stack**: React 19, TypeScript, Vite, R3F, Drei, Three.js, Custom GLSL
**Public name**: Sri Yantra Scrollytelling (on research page)

## What This Is

Interactive 3D Sri Yantra mandala visualization. 50,000 particles form sacred geometry on scroll, explode, converge into a cylindrical tunnel, and rush infinitely toward the camera. Originally generated by Kimi AI, then iterated with Codex and Claude.

## Scroll System

Uses Drei `ScrollControls` (inside Canvas) + `useScroll` hook:
- `ScrollControls pages={4} damping={0.15}` — creates 4 pages of scroll space
- `useScroll().offset` — gives 0→1 dampened scroll progress
- `scrollProgressRef` created in App, shared with both Scene (writes) and HUD (reads via rAF)
- Mandala reads the ref each frame and passes to `uScrollProgress` uniform
- HTML overlay content goes inside `<Scroll html>` component

**Critical lesson**: Custom `window.scrollY` scroll listeners DO NOT work when the canvas is `position: fixed` with `pointer-events: none` overlays. Drei ScrollControls is the standard R3F solution.

## Scroll Timeline (4 Phases)

| Range | Phase | What Happens |
|-------|-------|-------------|
| 0-50% | BUILD | Particles fly from off-screen ring to Sri Yantra mandala formation |
| 50-75% | EXPLOSION | Mandala explodes outward with spiral rotation (shortened range) |
| 75-85% | CONVERGENCE | Exploded particles smooth-blend into cylindrical tunnel formation |
| 85-100% | TUNNEL | Particles rush through infinite tunnel via Z-modulo recycling |

### Vertex Shader — Key Functions
- `getTunnelPosition(phase, scale, zOff)` — cylindrical coords with Z-modulo wrap
- Tunnel radius 1.8-3.0, Z range -20 to +6, spiral twist `zPos * 0.08 + uTime * 0.3`
- Convergence uses `mix(explosionEnd, tunnelPos, smoothstep_t)` for seamless transition
- Mesh transforms (rotation, tilt, scale) dampened to zero during tunnel via `tunnelDampen`

### Fragment Shader — Phase-Aware Alpha
- Build: full alpha with stagger fade-in
- Explosion: dims to 0.7 (particles don't die)
- Convergence: fades back to 1.0
- Tunnel: distance fog (`farFade * nearFade`) hides recycling seam
- Cosmic tint (cool blue shift) during tunnel: `mix(color, color * vec3(0.8, 0.95, 1.2), vTunnelPhase * 0.4)`

### Scroll Overlay Cards
- Card 1 "Sacred Geometry" (0-40%): slide up, hold, exit up
- Card 2 "The Infinite" (60-85%): slide up, hold, fade in place
- Card 3 "Cosmic Tunnel" (85-100%): slide up, hold, **implodes** to center point (scale→0, rotateX→45°)
- Flash overlay (99-100%): radial white gradient radiates from center via CSS scale transform

## Shader Uniforms / Attributes

```glsl
uniform float uTime;              // clock time
uniform float uScrollProgress;    // 0-1 from Drei useScroll
uniform float uVelocity;          // normalized scroll speed
uniform float uHover;             // hover intensity
uniform float uPulse;             // click pulse
uniform vec2 uPointer;            // pointer position

attribute vec3 aTargetPosition;   // mandala formation position
attribute vec3 aStartPosition;    // off-screen ring (radius 3.0-5.0)
attribute vec3 aColor;            // from 9-color jewel palette
attribute float aScale;           // size variation (0.7-1.8)
attribute float aPhase;           // radial-distance-based (0=center, 1=edge)
```

## Critical Dev Notes

- **Shader changes require server restart**: Vite HMR does NOT recompile Three.js ShaderMaterial GPU programs. Kill server → `rm -rf node_modules/.vite` → restart → hard refresh (Cmd+Shift+R).
- **Point size history**: 800 (original, 300px blobs) → 150 (37px, still large) → 60 (15px) → 25 (6px, sand scale).
- **NormalBlending** replaced AdditiveBlending to prevent white blowout in dense areas.
- **Start positions**: Flat ring at radius 3.0-5.0 in XY plane. All outside camera frustum at scroll 0%.

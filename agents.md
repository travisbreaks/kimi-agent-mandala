# Kimi Agent Mandala — Agent Context

**Updated**: 2026-02-07 | **Stack**: React 19, TypeScript, Vite, R3F, Drei, Three.js, Custom GLSL, Tailwind CSS

## What This Is

Interactive 3D Sri Yantra mandala visualization. 50,000 particles form sacred geometry on scroll, then shatter to reveal a fractal tunnel. Originally generated by Kimi AI, then iterated with Codex and Claude.

## Scroll System

Uses Drei `ScrollControls` (inside Canvas) + `useScroll` hook:
- `ScrollControls pages={4} damping={0.15}` — creates 4 pages of scroll space
- `useScroll().offset` — gives 0→1 dampened scroll progress
- `scrollProgressRef` created in App, shared with both Scene (writes) and HUD (reads via rAF)
- Mandala reads the ref each frame and passes to `uScrollProgress` uniform
- HTML overlay content goes inside `<Scroll html>` component

**Critical lesson**: Custom `window.scrollY` scroll listeners DO NOT work when the canvas is `position: fixed` with `pointer-events: none` overlays. Drei ScrollControls is the standard R3F solution.

## Shader Animation

### Build Phase (scroll 0→0.5)
```glsl
float t = uScrollProgress * 2.0;  // 0→1
// Per-particle stagger: center particles arrive first
float pT = clamp((t - aPhase * 0.3) / 0.7, 0.0, 1.0);
float easedPT = 1.0 - pow(1.0 - pT, 3.0);  // ease-out cubic
finalPosition = mix(aStartPosition, aTargetPosition, easedPT);
vBuildAlpha = smoothstep(0.0, 0.15, pT);
```

### Explosion Phase (scroll 0.5→1.0)
```glsl
float t = (uScrollProgress - 0.5) * 2.0;
vec3 explosionDir = normalize(aTargetPosition);
finalPosition = aTargetPosition + explosionDir * 30.0 * pow(t, 2.0);
// + spiral rotation via mat2
```

### Fragment Shader (Sand Grain)
- Irregular shape via noise-distorted discard threshold
- Instance color dominant (jewel-tone palette), subtle grain texture on top
- Edge darkening for 3D grain illusion
- Occasional sparkle specks
- NormalBlending (not Additive — prevents white blowout)

## Shader Uniforms / Attributes

```glsl
uniform float uTime;              // clock time
uniform float uScrollProgress;    // 0-1 from Drei useScroll
uniform float uVelocity;          // normalized scroll speed
uniform float uHover;             // hover intensity
uniform float uPulse;             // click pulse
uniform vec2 uPointer;            // pointer position

attribute vec3 aTargetPosition;   // mandala formation position
attribute vec3 aStartPosition;    // off-screen ring (radius 3.0-5.0)
attribute vec3 aColor;            // from 9-color jewel palette
attribute float aScale;           // size variation (0.7-1.8)
attribute float aPhase;           // radial-distance-based (0=center, 1=edge)
```

## Critical Dev Notes

- **Shader changes require server restart**: Vite HMR does NOT recompile Three.js ShaderMaterial GPU programs. Kill server → `rm -rf node_modules/.vite` → restart → hard refresh (Cmd+Shift+R).
- **Point size history**: 800 (original, 300px blobs) → 150 (37px, still large) → 60 (15px) → 25 (6px, sand scale).
- **NormalBlending** replaced AdditiveBlending to prevent white blowout in dense areas.
- **Start positions**: Flat ring at radius 3.0-5.0 in XY plane. All outside camera frustum at scroll 0%.

## Deployment

**Current**: Local only (`npm run dev` → localhost:5173)

**To deploy to travisbreaks.org/research/:**
1. Create `netlify.toml` in project root (SPA redirect, `npm run build`, publish `dist/`)
2. Build is already configured: `tsc -b && vite build`
3. Create Netlify site + add `NETLIFY_SITE_ID_KIMI` GitHub secret
4. Add deploy job in `.github/workflows/deploy-netlify.yml`
5. Link from travisBREAKS research section (`travisBREAKS/research/index.html`)

**Alternative**: Deploy as a subdirectory of travisBREAKS (copy built dist/ into `travisBREAKS/research/kimi-mandala/`). Simpler but requires manual build step.
